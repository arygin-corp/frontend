  <p align="center">
    Global Enterprise Data Marketplace is a self-service data marketplace portal which enables TMNA users, business partners, affiliates, and contingent workers to discover and request Readily Available Data, Analytics, and Reports at Toyota. The Data Marketplace provides all Toyota users with the ability to search, discover and request any data, available in any form, at Toyota. This reduces the reliance on Data Stewards, Data Analysts, and other individuals/groups related to data management, and also saves the users a lot of time trying to find or request access to data.
  </p>

  <h1 align="center">BUILD COMMANDS</h1>
  <p align="center">These are the essential commands to build the Global Data Marketplace Application.</p>

  <h3 align="center">INSTALLATION COMMANDS</h3>
  <p align="center"><strong>BASIC:</strong> npm i</p>
  <p align="center"><strong>LEGACY:</strong> npm i --legacy-per-deps</p>

  <h3 align="center">LOCALHOST BUILD</h3>
  <p align="center"><strong>LOCAL:</strong> npm run start</p>

  <h3 align="center">PRODUCTION NO VERSION BUILD</h3>
  <p align="center"><strong>DEMO:</strong> npm run demo</p>
  <p align="center"><strong>QA:</strong> npm run qa</p>
  <p align="center"><strong>STAGE:</strong> npm run stage</p>
  <p align="center"><strong>PRODUCTION:</strong> npm run prod</p>

  <h3 align="center">PRODUCTION PATCH BUILD</h3>
  <p align="center"><strong>DEMO:</strong> npm run demo-patch</p>
  <p align="center"><strong>QA:</strong> npm run qa-patch</p>
  <p align="center"><strong>STAGE:</strong> npm run stage-patch</p>
  <p align="center"><strong>PRODUCTION:</strong> npm run prod-patch</p>

  <h3 align="center">PRODUCTION MINOR BUILD</h3>
  <p align="center"><strong>DEMO:</strong> npm run demo-minor</p>
  <p align="center"><strong>QA:</strong> npm run qa-minor</p>
